# LiveCore · 智核

模块化、可扩展的 **B 站直播间智能互动框架**。从底层连接开始逐层叠加能力：协议解析 → 事件分发 → 人格 / 情感 → 行为调度。默认停在「建议」这一层，**不会向直播间发送弹幕、点赞或分享**。

> 仅供技术实验与学习。请遵守哔哩哩哩弹幕网用户协议，自行承担账号风险。自动刷屏、伪造在线、绕过风控不在本项目范围内。

## 分层架构

```
应用入口  读取配置，启动连接 / 消息 / AI / 行为
    │
业务逻辑  消息处理器 · 事件分发器 · 行为调度器
    │
AI 集成   人格 prompt · 情感标签 · 规则引擎降级
    │
网络通信  WebSocket · 25s 心跳 · 指数退避重连
    │
基础设施  配置 · 日志 · 出站适配器（默认模拟器）
```

阶段实现见 Pull Requests。默认出站适配器是本地模拟器，不会调用 B 站发送接口。
